# DriveFleet 🚗

A modern car rental platform where users can browse vehicles, add their own cars, manage bookings, and reserve vehicles for their travel needs.

## 🌐 Live Site

**Live URL:** https://https://drivefleet-client-eight-sooty.vercel.app/

---

## ✨ Features

* Browse and search available vehicles by name and category.
* View detailed information for each car before booking.
* Add, update, and delete personal vehicle listings.
* Book cars and manage reservations from the My Bookings page.
* Automatic booking count tracking for every vehicle.
* Protected routes for authenticated user-specific data.
* Responsive design optimized for mobile, tablet, and desktop devices.
* Dynamic filtering system for quick vehicle discovery.
